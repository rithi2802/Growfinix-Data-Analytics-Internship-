# Growfinix-Data-Analytics-Internship-Task 1
## Task 1: Data Collection and Data Cleaning- **Tools Used:** Microsoft Excel, ChatGPT/Gemini AI- **Dataset:** Raw Sales / Student Performance Dataset ### Cleaning Steps Performed: 
1. Removed duplicate rows using Excel Remove Duplicates tool.
2. Identified missing values using Go To Special (Blanks) and filled with Average / Unknown.
3. Standardized text formatting and removed extra spaces using `TRIM()` and `PROPER()` formulas.
4. Fixed inconsistent date and number formats.
5. Used AI to validate data quality issues and cleaning formulas.
